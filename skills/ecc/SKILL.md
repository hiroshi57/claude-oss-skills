# ECC（affaan-m/ECC）

## 何のツールか
コーディングエージェントに開発の流れ（計画・実装・テスト検証・別コンテキストでのレビュー・重要事項の記憶・再利用可能なスキル化）を組み込む開発ハーネスです。

## 使いどころ
エージェントにチーム開発に近い進め方をさせたいとき、繰り返し成功したパターンをスキルとして残したいとき。

## 導入（Claude Code のコマンド）
```
/plugin install ecc@ecc
```
Codex・Cursorなど他の実行環境にも対応します。

## 基本の使い方
導入後、各工程をエージェントに順に実行させます。
